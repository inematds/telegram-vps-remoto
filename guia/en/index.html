How it works

The AI looks. The bot makes changes, after you say yes.

Think of a building: the AI is a consultant who can look at the workroom (the bot's working folder) and make suggestions; the bot is the doorman with a list of who can enter and what can be done; and only you sign off on the order.

You ask in Telegram→the bot checks that it's you→the AI only reads and replies→if something needs to change: proposal + "Confirma? (sim/não)" (Confirm? (yes/no))→"sim" (yes)→the bot carries it out and logs it

🚪 Only you can talk to it

The bot has an owner list. Anyone not on it gets "Este bot é privado." (This bot is private.) and is logged. Empty list: no one gets in.

👀 The AI only reads, and only in the working folder

It can read what's in the bot's working folder. Elsewhere on the server, it can only see disk space and the names of folders and files, never their contents. Keys, passwords, and logins stay out.

✍️ Changes become proposals

A request to delete, move, or create something comes back as a proposal: what will change and the exact commands. The bot carries it out after your "yes," using only a short list of simple commands, and only inside the working folder.

🛑 "No" really cancels

"sim" (yes) and "sim, pode apagar" (yes, you can delete it) confirm. "sim, não apaga" (yes, don't delete it), "sim, mas antes…" (yes, but first…) or "pode listar antes?" (can you list it first?) don't confirm. The request is valid for only 10 minutes.

📁 The working folder

It's a folder just for the bot, next to it on the server (area, inside the kit folder), and it starts empty. Put the files you want it to read or organize there. You can point it to another folder in a configuration line, but only choose a folder you're okay with it reading and changing after you say yes.

📒 Everything is logged

Every request, proposal, yes, refusal, and result is saved in a log file that only you can read on the server. The server also keeps the bot's own log (the lines it writes while running), which shows who tried to talk to it.

🌎 In your language

The AI’s answers come in the language you write in. The bot’s fixed messages are in Portuguese: "Este bot é privado." (This bot is private.), "Pronto. Peça o que quiser…" (Ready. Ask for anything…, the reply to /start), "Vou fazer:" (I will do:), "Comandos:" (Commands:), "Confirma? (sim/não)" (Confirm? (yes/no)), "Feito:" (Done:), "Cancelado. Nada foi mudado." (Cancelled. Nothing was changed.), "Esse pedido expirou…" (This request expired…), "Isso eu não faço por aqui…" (I don’t do that from here…) and "Deu erro:" (Error:). To confirm, "sim", "sí" or "yes" all work.

🧱 It doesn't inherit anything from the machine

If you've already allowed commands for Claude Code on the server, the bot ignores that: only its own safety checks apply.

⚠️ What this doesn't promise

It can't make Claude get everything right: it can give a wrong answer. What is guaranteed is that it won't change anything without going through a proposal and your "yes." The bot manages its working folder, not the whole server: keep using the terminal to work on the system, databases, or other projects.

Getting started

Ask your AI to install the kit

You don't install anything by hand. Claude Code on your VPS reads the project, checks the server, and sets everything up. You paste the bot token yourself into a terminal command, outside the conversation, so it never passes through the AI.

0. Do you only have root?

Log in to your VPS as root, open Claude Code (if you don't have it yet, install it from the official page; it's a single command to paste), and paste the request below. It creates your regular user, enables the option that keeps the bot running after you log out, and tells you how to log in as the new user. In that user, Claude Code is installed and logged in once more (just this once).

1. Create your bot

On Telegram, message @BotFather, send /newbot, choose a name and a username ending in "bot." It gives you a token (a long password for the bot). Save it.

2. Paste the request into Claude Code on your VPS

As your regular user, open Claude Code and paste the request below. It explains the plan and waits for your "yes." Installation takes 2 to 5 minutes and uses a few short Claude subscription calls to test the safety checks.

3. Tell it you're the owner

At the end, send /start to the bot. The AI will help you find your Telegram ID in the bot's log and save you as the owner. That's it: make requests from your phone.

Common questions

Before you start

Do I need to know how to code?

No. Your AI installs it; you just create the bot on Telegram, paste the token when asked, and say "yes."

Does it cost anything?

The kit is free. The bot uses Claude Code through your Claude subscription; there's no API key (the password some AIs use to charge by usage) or pay-per-use fee. You already pay for the VPS.

What if someone finds my bot?

It replies "Este bot é privado." (This bot is private.) to anyone who isn't an owner and logs the attempt. No one outside your list can make requests.

Can it change anything on the server?

No. It reads and changes things only inside its working folder, and only after your "yes." It can only see the rest of the server from the outside (disk space, names). That means it can't work with, for example, system logs (files where programs record what they've done) unless you copy them into its folder.

Does it work on Windows or Mac?

The kit is for Linux servers; we tested it on Ubuntu 24.04. You use your phone to talk to it.

How is it different from the step-by-step guide?

The step-by-step guide teaches you to build the same bot one step at a time. This kit comes ready to use, with an installer.
