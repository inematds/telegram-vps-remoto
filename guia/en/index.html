How it works

The AI looks. The bot makes changes, after you say yes.

Think of a building: the AI is a consultant who can look at the workroom and make suggestions; the bot is the doorman with a list of who can enter and what can be done; and only you sign off on the order.

You make a request in Telegram→the bot checks that it's you→the AI only reads and replies→if something needs to change: proposal + "Confirma?" (Confirm?)→"sim" (yes)→the bot runs it and logs it

🚪 Only you can talk to it

The bot has a list of owners. Anyone not on it gets "Este bot é privado." (This bot is private.) and the attempt is logged. If the list is empty, no one gets in.

👀 The AI only reads, and only in the workroom

It can read what's in the bot's working folder. Elsewhere on the server, it can only see disk space and folder and file names, never their contents. Keys, passwords, and logins stay out of reach.

✍️ Changes become proposals

A request to delete, move, or create something comes back as a proposal: what will change and the exact commands. The bot runs them after your "sim" (yes), using only a short list of simple commands and only inside the working folder.

🛑 "Não" (no) really cancels

"sim" (yes) and "sim, pode apagar" (yes, you can delete it) confirm. "sim, não apaga" (yes, don't delete it), "sim, mas antes…" (yes, but first…) and "pode listar antes?" (can you list it first?) do not confirm. Each request is valid for only 10 minutes.

📒 Everything is logged

Every request, proposal, yes, refusal, and result is recorded in a log that only you can read on the server.

🧱 It inherits nothing from the machine

If you've already allowed commands for Claude Code on the server, the bot ignores that: only its own safeguards apply.

⚠️ What this doesn't promise

It can't guarantee Claude will always get everything right: it may give a wrong answer. What is guaranteed is that it won't change anything without going through a proposal and your "sim" (yes). And the bot manages its working folder, not the entire server: to change the system, database, or other projects, keep using the terminal.

Getting started

Ask your AI to install the kit

You don't install anything by hand. Claude Code on your VPS reads the project, checks the server, and sets everything up. You paste the bot token yourself so it never passes through the AI.

1. Create your bot

In Telegram, message @BotFather, send /newbot, choose a name and a username ending in "bot." It gives you a token (a long password for the bot). Save it.

2. Paste the request into Claude Code on the VPS

Log in to the VPS with your user account (not root), open Claude Code, and paste the request below. It explains the plan and waits for your "sim" (yes).

3. Tell it you're the owner

At the end, send /start to the bot. The AI will help you find your Telegram number and register you as the owner. That's it: send requests from your phone.

Do I need to know how to code?

No. Your AI installs it; you only create the bot in Telegram, paste the token when asked, and say "sim" (yes).

Does it cost anything?

The kit is free. The bot uses Claude Code through your Claude subscription; there's no API key or pay-per-use charge. You're already paying for the VPS.

What if someone finds my bot?

It replies "Este bot é privado." (This bot is private.) to anyone who isn't an owner, and logs the attempt. No one outside your list can make requests.

Can it change anything on the server?

No. It reads and changes things only inside its working folder, and only after your "sim" (yes). It only sees the rest of the server from the outside (disk space and names).

Does it work on Windows or Mac?

The kit is for Linux servers; we tested on Ubuntu 24.04. You use your phone to talk to it.
